## 👨‍💻 About

I'm an AI Engineer with a strong foundation in machine learning, deep learning, and data science. I build end-to-end AI solutions: training and evaluating models, designing AI workflows and agents, and deploying them as reliable backend services, including on self-hosted infrastructure.

My work spans healthcare and education, and I publish open-source projects on GitHub. I like understanding how things work under the hood, from the math behind a model to the API that serves it.
